# Runtime v0.1 proposal

Add a local deterministic execution layer for existing MSO coordination files. It reduces repeated Manager reasoning without creating, directing, or evaluating Agents.

## Scope

Schema validation, scheduling, conflicts, status transitions, handoff completeness, bounded context, and a Node.js CLI.

## Non-goals

Agent launch, Git/worktree automation, shell execution, model routing, storage services, and network services.
